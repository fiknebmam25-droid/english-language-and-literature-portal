# English Language and Literature Portal

Public PWA prototype for the **Department of English Language and Literature, Assosa University**.

## Local use

Run a local server:

```bash
python -m http.server 8000
```

Open `http://localhost:8000`.

## GitHub Pages

1. Open repository **Settings**.
2. Open **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main** and **/(root)**.
5. Save and wait for deployment.

Enable Edit Mode with the fixed button in the lower-left corner.

## Limitation

This prototype is currently offline-only and is not connected to Google Sign-In. It stores content in local browser storage and does not provide secure shared accounts or cloud uploads.
